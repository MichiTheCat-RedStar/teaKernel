Различные тесты возможностей ядра

Ничего из находящегося здесь не гарантирует то, что это будет в финальной версии ядра

Пример:
	test0-1	- работа подразумевала только ассемблер
	test2	- уже осуществлён переход на C
	testN	- всё что есть в актуальном тесте на момент написания readme.txt (test16) могло поменяться, например уже есть планы убрать мусор, вроде teaprint, а так же сделать систему более близкой к микроядру, то есть переписать все функции так, чтобы вместо них был только минимальный набор инструментов
