Код, созданный для teaKernel, но будет использоваться в дальнейшем в проектах
Создан для создания дерева файлов

Изначальная идея была пойти по пути наименьшего сопротивления и просто заменять в Linux tree все символы под мой "Компактный" формат, но по итогу я всё же решил лучше сделать этот скрипт, да и его в дальнейшем можно будет доработать


Пример использования:

Открыть файл, указать пусть, скопировать с терминала дерево с помощью Ctrl+Shift+C, может в дальнейшем добавлю поддержку перенаправления stdin, что позволит вставлять файл в пайпы, либо добавить поддержку аргументов
